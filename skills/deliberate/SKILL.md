# Deliberate

Define the question, relevant evidence, established constraints, what is open, and the stopping condition. Use the participants and models the user authorized. Each participant is a reasoning peer; give useful context without assigning a predetermined conclusion or a permanent advocate role.

Obtain initial positions, then exchange the substantive arguments. Challenge assumptions and proposed tradeoffs with evidence. The principal contributes its own position and revises it when warranted; collecting separate reports alone is not deliberation.

Circulate the provisional synthesis for correction. State what converged, what changed, and what remains disputed or unknown. Silence is not agreement. Stop when the material question is resolved or the agreed round/effort limit is reached; do not fabricate consensus to satisfy an acceptance target.

Choose the execution mechanism using the orchestration skill: use native agent tools whenever they meet the assignment. A panel using several compatible models still uses native execution. Use Harness execution and message tools only for an eligible managed assignment. Keep context bounded to the question and relevant evidence, and preserve the shared execution limits. An explicitly requested expensive model remains that model; report unavailability instead of silently choosing another.

The output is a concise decision synthesis with reasons, relevant evidence, and unresolved tradeoffs. Persist useful conclusions through work or memory tools when appropriate; do not archive private reasoning traces. Deliberation does not itself authorize implementation or publication beyond the user's request.
