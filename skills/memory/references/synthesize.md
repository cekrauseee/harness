# Synthesize memory

Choose a bounded scope: an environment, topic, or set of captures. Read the relevant consolidated records and candidates, following source references only when they affect confidence or the decision.

For each useful claim, consider its expected reuse, specificity, evidence, scope, and freshness. Combine duplicates and supersede obsolete statements when supported. Preserve unresolved conflicts as uncertainty; a newer capture or a confident assertion is not proof by itself. Discard noise, transient progress, secrets, and unsupported generalizations.

Organize around questions a future agent will search for. Prefer a focused title, a short actionable statement, relevant conditions, and source references. Split independent topics when it improves retrieval; avoid a taxonomy that costs more to maintain than it helps. Global scope requires cross-environment applicability.

Write the English record through memory/record tools using the observed revision. On conflict, reread and reconcile rather than overwriting another agent's work. Verify the saved record before deleting a processed capture; preserve the capture if the update fails. No tool performs this judgment for you.

Report the meaningful additions, corrections, exclusions, and unresolved questions briefly. The same synthesis technique can improve other context documents, but their authority and ownership still come from their module.
