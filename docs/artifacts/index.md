# Artifacts

Artifacts are versioned, user-facing HTML visualizations about a project. They are documentation outputs, not application prototypes or Harness memory.

## Contract

- Store final artifacts in `docs/artifacts/<slug>.html`.
- Link every artifact from this index and route this index from `docs/index.md`.
- Use semantic, accessible, static, self-contained HTML.
- Use neutral Harness presentation for readability.
- Do not infer or reproduce the project's brand, interface, or visual language.
- Do not use frameworks, build steps, backends, external scripts, fonts, images, or stylesheets.
- Keep drafts and intermediate data in the temporary Harness workspace.
