Commit, push, PR publication, merge, release and remote metadata changes are separate authorized actions.

Suggested Harness repository description:

> Shared project continuity, knowledge and cooperative task coordination for agents, stored in local files.

Suggested topics: `agent-skills`, `project-memory`, `continuity`, `task-coordination`, `python`, `codex`, `claude-code`.

Keep the existing repository URL and MIT authorship. Do not add a site, badge or unverified marketplace URL. Before publishing, run the checks in [development](development.md), review the actual diff and generated runtime integrity, confirm author/committer configuration, and obtain authorization for the specific publishing operations. Local installation evidence does not establish public indexing or cache refresh.
